1. 证明题
证明y = C1ex + C2e−x −2(cos x + x sin x) 是方程y′′ −y = 4x sin x 的通解。
证明：首先计算y 的一阶和二阶导数：
y = C1ex + C2e−x −2(cos x + x sin x)
y′ = C1ex −C2e−x −2(−sin x + sin x + x cos x) = C1ex −C2e−x −2x cos x
y′′ = C1ex + C2e−x −2(cos x −x sin x)
代入原方程：
y′′ −y = [C1ex + C2e−x −2(cos x −x sin x)] −[C1ex + C2e−x −2(cos x + x sin x)]
= −2 cos x + 2x sin x + 2 cos x −2x sin x = 4x sin x
因此，给定的函数满足原方程，且含有两个任意常数，故为通解。
