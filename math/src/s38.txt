1. 铀衰变问题
题目：设放射性元素铀的衰变速度与当时未衰变的铀原子的含量M 成正比。已知
t = 0 时铀的含量为M0，求在衰变过程中铀含量M 与时间t 的函数关系。
解答：根据题意，衰变速度与含量成正比，即
dM
dt = −kM,
其中k > 0 为衰变常数。这是一个一阶线性齐次微分方程。
分离变量：
dM
M = −k dt.
积分得：
ln |M| = −kt + C,
其中C 为积分常数。所以
M = e−kt+C = eCe−kt.
由初始条件t = 0 时M = M0，得eC = M0。因此
M(t) = M0e−kt.
这就是铀含量随时间变化的指数衰变规律。
答案：M(t) = M0e−kt
2. RL 电路问题
题目：设有一个由电阻R = 10 Ω，电感L = 2 H 和电源电压E = 20 sin 5t V 串联
组成的电路。开关S 合上后，电路中有电流通过。求电流I 与时间t 的关系。
解答：根据基尔霍夫电压定律，电路方程为
LdI
dt + RI = E.
代入数值L = 2, R = 10, E = 20 sin 5t，得
2dI
dt + 10I = 20 sin 5t.
化简为：
dI
dt + 5I = 10 sin 5t.
这是一阶线性非齐次微分方程。先解齐次方程：
dI
dt + 5I = 0.

齐次通解为：
Ih = Ae−5t.
求特解。非齐次项为10 sin 5t，设特解形式为：
Ip = B cos 5t + C sin 5t.
代入方程：
dIp
dt = −5B sin 5t + 5C cos 5t,
−5B sin 5t + 5C cos 5t + 5(B cos 5t + C sin 5t) = 10 sin 5t.
整理得：
(−5B + 5C) sin 5t + (5C + 5B) cos 5t = 10 sin 5t.
比较系数：
−5B + 5C = 10,
5B + 5C = 0.
解方程组：由第二式得B = −C，代入第一式：
−5(−C) + 5C = 10 ⇒5C + 5C = 10 ⇒10C = 10 ⇒C = 1,
B = −1.
所以特解为：
Ip = −cos 5t + sin 5t.
通解为：
I(t) = Ih + Ip = Ae−5t + sin 5t −cos 5t.
通常开关合上时电流为零，即初始条件I(0) = 0。代入：
I(0) = Ae0 + sin 0 −cos 0 = A −1 = 0 ⇒A = 1.
因此特解为：
I(t) = e−5t + sin 5t −cos 5t.
答案：I(t) = e−5t + sin 5t −cos 5t
