(1) y = 3x² −x³
定义域：(−∞, +∞)
导数分析：
y′ = 6x −3x² = 3x(2 −x)
y′′ = 6 −6x = 6(1 −x)
临界点：令y′ = 0，得x = 0 或x = 2
• 当x < 0 时，y′ < 0，函数单调递减
• 当0 < x < 2 时，y′ > 0，函数单调递增
• 当x > 2 时，y′ < 0，函数单调递减
• x = 0 处：y = 0，y′′ = 6 > 0，局部极小值
• x = 2 处：y = 3 · 4 −8 = 4，y′′ = −6 < 0，局部极大值
拐点：令y′′ = 0，得x = 1，y = 3 · 1 −1 = 2
• 当x < 1 时，y′′ > 0，函数为凸函数
• 当x > 1 时，y′′ < 0，函数为凹函数
渐近线：无垂直渐近线；无水平渐近线；斜渐近线：当x →±∞，y ∼−x³，故无斜渐近线。
关键点：
• x = −1，y = 3 · 1 −(−1) = 4
• x = 3，y = 3 · 9 −27 = 0
图像特征：函数在x = 0 处取得极小值0，在x = 2 处取得极大值4，在x = 1 处有拐点。图
像从左下方无限上升至拐点，然后上升至极大值，最后下降至右下方。
