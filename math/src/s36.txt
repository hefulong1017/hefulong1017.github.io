1. 判断下列各组函数在其定义区间内是否线性相关
1. 题目：x−2, x³
解答：考虑线性组合c1x−2 + c2x³ = 0。
定义区间：x ≠ 0（因为x−2 在x = 0 处无定义）。
假设存在不全为零的常数c1, c² 使得等式对所有x ≠ 0 成立。
如果c1 ≠ 0，当x →0 时，x−2 →∞而x³ →0，等式不可能成立。
如果c² ≠ 0，当x →∞时，x³ →∞而x−2 →0，等式也不可能成立。
因此，唯一的可能是c1 = c² = 0，所以函数线性无关。
答案：线性无关
2. 题目：sin x, cos x
解答：考虑线性组合c1 sin x + c² cos x = 0。
定义区间：全体实数。
假设等式对所有x 成立。
取x = 0：c1 · 0 + c² · 1 = 0 ⇒c² = 0
取x = π
2：c1 · 1 + c² · 0 = 0 ⇒c1 = 0
因此c1 = c² = 0，所以函数线性无关。
答案：线性无关
3. 题目：ex, xex
解答：考虑线性组合c1ex + c2xex = 0，即ex(c1 + c2x) = 0。
定义区间：全体实数。
由于ex ≠ 0，所以c1 + c2x = 0 必须对所有x 成立。
这只有在c1 = 0 且c² = 0 时才能成立。
因此函数线性无关。
答案：线性无关
4. 题目：0, ex
解答：考虑线性组合c1 · 0 + c2ex = 0。
定义区间：全体实数。

取c1 = 1, c² = 0，则等式成立且c1, c² 不全为零。
因此函数线性相关。
说明：任何函数与零函数都是线性相关的。
答案：线性相关
