WHAT IT DOES

∂

方程直接写

支持 \(x,y,z\) 与时间 \(t\)，可写变系数、散度形式和常见初边值条件，页面内实时编译 LaTeX。

3D

从 1D 到 3D

已通过方程族的 1D、2D、3D 扩展模板，包含坐标依赖系数示例；模板载入后仍可逐项修改。

∿

结果能看，也能查

固定坐标看曲线和曲面切片，单点查询具体数值，批量结果导出 CSV。

◌

多版本候选

V5–V8 数值候选并排比较，保留训练过程与误差信息，方便判断结果是否可信。

部署到自己的容器

DOCKER / STREAMLIT

PUBLIC RELEASE V2
下载右侧发布包，解压到仓库根目录，确认 Dockerfile 在根目录。
在支持 Dockerfile 的平台创建 Web 服务，构建上下文选仓库根目录。
容器读取平台注入的 PORT，健康检查路径 /_stcore/health。
# 本机预览
docker build -t pinnlab-public .
docker run --rm -p 8501:8501 pinnlab-public

不需要 GPU。默认镜像含公式图片识别，建议至少 4 GB 内存；资源紧张时可在构建时关闭 OCR。

包里有什么

Streamlit 界面、PINN 求解器、V5–V8 研究代码、方程模板与 Dockerfile。公开模式限制单任务 20 秒，适合体验和教学演示。
