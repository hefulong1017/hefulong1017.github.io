WHAT IT DOES

∂

Write the equation directly

Supports \(x,y,z\) and time \(t\), variable coefficients, divergence form and the usual initial and boundary conditions; LaTeX compiles live on the page.

3D

From 1D to 3D

Equation families come with 1D, 2D and 3D templates, including coordinate-dependent coefficient examples; everything stays editable once a template is loaded.

∿

Results you can look at and query

Fix a coordinate to see curve and surface slices, query single points for exact values, and export batch results as CSV.

◌

Multiple candidate runs

V5–V8 candidates sit side by side with their training history and error data, so you can judge whether a result is trustworthy.

Deploy to your own container

DOCKER / STREAMLIT

PUBLIC RELEASE V2
Download the release, unpack it into the repository root, and check that Dockerfile sits in the root.
Create a web service on any platform that supports Dockerfiles, with the repository root as the build context.
The container reads the PORTinjected by the platform; the health-check path is /_stcore/health。
# local preview
docker build -t pinnlab-public .
docker run --rm -p 8501:8501 pinnlab-public

No GPU needed. The default image includes formula OCR, so allow at least 4 GB of memory; on a tight machine, turn OCR off at build time.

What is in the release

A Streamlit interface, the PINN solver, the V5–V8 research code, equation templates and a Dockerfile. Public mode caps each job at 20 seconds, which suits demos and teaching.
