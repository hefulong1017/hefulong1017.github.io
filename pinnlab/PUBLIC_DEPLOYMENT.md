# PINNLab 公共体验版部署

该发布包启动 `interface_v6/app.py`，提供 LaTeX 方程输入、物理条件设置、V5/V6/V7/V8 数值候选、曲线与曲面查看、逐点和 CSV 批量查询。公开模式将每个进程限制为一个计算任务，预算最多 20 秒，并限制迭代数、点数和特征规模。每位访客的当前结果保存在自己的浏览会话中；容器不保存上传文件或计算结果。

## 本机预览

安装 Docker 后，在解压后的发布目录运行：

```bash
docker build -t pinnlab-public .
docker run --rm -p 8501:8501 pinnlab-public
```

打开 `http://localhost:8501`。公开服务器需要允许容器访问 CPU 和外网软件源；运行时不需要 GPU。

LaTeX 输入可声明 `x,y,z` 三个空间坐标，并可附加时间 `t`。交互版提供 V6 已通过方程族的 1D、2D、3D 扩展模板和坐标依赖系数示例；这些扩维模板尚未经过逐维独立精度审计。三维空间解可逐点查询，并通过固定坐标的二维切片查看。

在 LaTeX 输入页展开“已通过方程族的 1D–3D 模板”，选择方程族、空间维数及是否使用空间变系数，再载入模板。模板会填入坐标、计算域、方程、参数及示例初边值；这些值均可继续编辑。Goursat 模板仅适用于二维。任意自定义坐标系数应写成明确表达式，例如 `\nabla\cdot((1+x+y+z)\nabla u)`；系数导数由散度展开纳入残差。

## 发布到托管平台

先解压发布包，并把解压目录中的文件直接放到 GitHub 仓库根目录，确认 `Dockerfile` 位于根目录。然后在支持 Dockerfile 的托管平台创建 Web 服务并连接该仓库，构建上下文选择仓库根目录；容器会监听平台提供的 `PORT`，默认端口为 `8501`，健康检查路径为 `/_stcore/health`。发布完成后，先打开平台提供的网址并完成一次试算，再把该网址加入个人主页或使用下方 iframe 嵌入。

默认镜像安装 Pix2Tex，让访客可以上传方程图片。识别模型约 116 MB，首次识别会从模型源下载权重；启用 OCR 建议选择至少 4 GB 内存的服务，并允许服务器访问模型源。若平台资源较小，可用 `docker build --build-arg ENABLE_EQUATION_OCR=0 -t pinnlab-public .` 关闭 OCR，访客仍可粘贴或编辑 LaTeX。上传图片会发送到托管服务器，页面会提示这一点。容器通过 `PORT` 环境变量读取托管平台分配的端口；本机预览默认使用 8501。

## 嵌入个人主页

获得公开应用网址后，把下方地址替换为平台网址。建议保留 850 像素以上高度；移动页面可将高度改为 `1000`。

```html
<iframe
  src="https://YOUR-PUBLIC-APP-URL/?embed=true"
  title="PINNLab 偏微分方程体验工作台"
  width="100%"
  height="900"
  loading="lazy"
  style="border:0"
  allow="clipboard-read; clipboard-write">
</iframe>
```

## 使用边界

这是用于演示和教学试用的研究原型。公式能被识别或编译，不等于数值解已经验证；求解结果需要结合方程条件和独立参考进行检查。不要宣传为“任意 PDE 自动求解”或“普遍优于差分/有限元”。

公共服务适合演示与教学试用，不用于生产计算。默认不开启账号登录；单个部署实例只处理一个求解任务。需要多人高并发时，应在托管平台前增加身份验证、请求配额和任务队列。
